# 流量统计

在节点编辑窗口中设置流量额度、口径、重置日、重置时区和统计网卡。NodeFlare 的用量是监控侧统计值，不能代替服务商的账单；请以服务商公布的周期、方向和单位为准。

## 额度与方向

流量限额填 `0` 表示不限。输入框支持 `100 G` 等带单位的写法，不带单位时按 GB 处理。

| 流量口径 | 与额度比较的值 |
| --- | --- |
| 上下行合计 | 上行 + 下行 |
| 取较大值 | 上下行中较大的一项 |
| 取较小值 | 上下行中较小的一项 |
| 仅上行 | 节点发送的数据量 |
| 仅下行 | 节点接收的数据量 |

流量告警使用同一口径。设置通知起始阈值的方法见[通知](/guide/alerts)。实时网速是当前速率，不是周期额度的消耗量。

## 重置时间

每个节点单独选择「流量重置日」和「流量重置时区」，默认时区为 `UTC`。它不跟随浏览器、后端操作系统或 Agent 系统时区。

- 重置日可设 1～31，在所选时区当日的零点进入新周期。
- 月份没有指定日期时取当月最后一天，例如 31 日在平年二月按 28 日处理。
- `Asia/Shanghai` 按北京时间；`America/Los_Angeles` 等地区时区会按其夏令时规则变化，不要固定用一个 UTC 偏移代替。
- 实际累计在下一次收到有效 Agent 上报时切换周期，不要求机器在零点执行定时命令。

例如同为每月 1 日：`UTC` 对应北京时间 1 日 08:00，`Asia/Shanghai` 对应北京时间 1 日 00:00。请根据服务商说明选择，不能仅因为自己在中国就默认使用北京时间。

::: warning
修改重置日或时区会在下一次有效上报时重新建立周期基线，重新开始累计。需要保留当前数值时，先记录用量，再按新周期检查并校正。已有流量校正偏移不会因改时区自动清除。
:::

## 统计网卡与校正

「统计网卡」留空时使用 Agent 的自动选择规则。可以用逗号分隔、`*` 通配和 `!` 排除，例如 `eth*,!eth1`。多网卡、网关或转发主机应明确选择需要计费的接口，避免把不同链路一起累计。

「上行流量当前值」「下行流量当前值」用于校正显示值。当前实现按修正偏移计算；修改网卡或重置周期后，检查数值是否仍符合你的统计口径。

后端根据 Agent 的累计计数器维护周期用量，而不是把历史图表上的网速点相加。因此历史聚合和保留天数不是流量重置开关。网卡变化、机器重启以及初次接入的基线可能与服务商不同；初次接入不会自动查询服务商本月已用流量。
