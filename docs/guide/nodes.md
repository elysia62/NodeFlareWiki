# 节点配置

后台「监控节点」管理节点信息、安装命令和展示顺序。先创建节点，再通过该行的下载按钮取得 Agent 安装命令，详见[安装 Agent](/guide/agent)。每台机器使用自己的节点和 Token，不要把同一条命令装到多台机器上。

## 展示与计费

| 设置 | 用途 |
| --- | --- |
| 名称、地区代码、分组、标签 | 整理节点在公开看板上的展示 |
| 隐藏节点 | 不在公开看板展示，仍可在后台管理；与价格无关 |
| 价格、币种、计费周期 | 价格是每个计费周期的费用，最低为 0；0 表示免费 |
| 到期日期、自动续费 | 自动续费按所填计费周期顺延到期时间，不会代替你向服务商付款；一次性计费不适用 |
| 关闭离线告警 | 只关闭本节点离线告警；其他提醒仍由对应条件决定 |

拖动列表中的排序手柄调整节点顺序。IP 地址在后台节点列表查看；公开页面不展示节点 IP 或 Token。

### 看板上的资产统计

看板顶部以「剩余价值」作为主金额，下方显示「每月成本」。两者口径不同：

| 指标 | 含义 |
| --- | --- |
| 剩余价值 | 按周期价格和全部剩余服务时间估算的价值，提前续费覆盖多个周期时不封顶 |
| 每月成本 | 将各节点的周期价格统一折算为 30 天成本后相加，一次性费用和免费节点不计入 |

计算方式与 Glassmorphism 主题一致：`剩余价值 = 周期价格 × 剩余天数 ÷ 周期天数`，未来不足一天按一天计。例如 ¥30 / 30 天的节点，剩 15 天计 ¥15，提前续费后剩 90 天计 ¥90；¥120 / 365 天、剩 730 天计 ¥240。剩余价值可以超过每月成本，两者没有大小约束。

每月成本按 `周期价格 × 30 ÷ 周期天数` 计算，再统一币种合计。例如 ¥36 / 30 天计 ¥36，¥90 / 90 天计 ¥30，¥120 / 365 天约计 ¥9.86。该值按看板所列节点的配置估算，不随在线或到期状态变化，也不代表本月实际扣款。

免费、已到期或未设置有效到期日期的节点，剩余价值记为 0；尚未到期的一次性计费节点按价格全额计。到期距离超过 36500 天时按长期节点处理，显示「长期」并计价格全额，避免把永久占位日期折算成巨额费用。

此数值是按所填价格和期限推算的展示值，不代表实际付款记录、退款金额或转售价格。无需填写服务器起始时间；自动续费仅顺延面板中的日期，也不代表服务商已扣款。

多币种会按每日汇率折算成统一币种，与展示币种相同的节点不需要汇率；其他币种汇率缺失时不计入，并在旁边标出数量。

## 采样与流量

- 「历史写入间隔」默认 60 秒，可设 15～3600 秒。
- 「实时上传间隔」默认 3 秒，可设 3～60 秒；逐秒采样不随它改成低频采样。
- 流量额度、统计网卡、重置日和时区见[流量统计](/guide/traffic)。
- 实时卡片、图表与长期历史的区别见[监控口径与采样](/guide/monitoring)。

## 远程执行

新节点的「允许远程执行」默认不勾选。此选项决定接下来生成的安装命令是否附带 `--disable-remote`，并不是远程切换 Agent 权限的开关。

| Agent 本地启动参数 | 实际权限 |
| --- | --- |
| 含 `--disable-remote` | Agent 拒绝远程执行，后台不能解除限制 |
| 不含 `--disable-remote` | Agent 允许接收远程任务，后台仍要求管理员启用并验证 TOTP |

开启的步骤：

1. 编辑节点，勾选「允许远程执行」并保存。
2. 点击节点下载按钮，复制新生成的安装命令。
3. 在被监控机器上执行命令，重新安装 / 配置 Agent 服务。

也可以在机器上修改已有服务的启动参数，移除 `--disable-remote` 后重启 Agent；systemd 服务修改后需先执行 `systemctl daemon-reload`。反过来，要在已安装的 Agent 上关闭权限，需要重新运行带该参数的安装命令，或在本地加上参数并重启。

Linux / macOS / FreeBSD 脚本使用 `--disable-remote`；Windows 安装脚本使用 `-DisableRemote`，底层 Agent 参数相同。手动更新会保留现有本地权限设置。

::: warning
仅在网页中勾选或取消勾选并保存，不会改变已运行 Agent 的权限。远程命令使用 Agent 进程的系统权限执行；脚本以管理员安装时尤其要谨慎。离开后台页面不会取消已经开始的命令，单条命令最多执行 10 分钟。
:::

## 删除节点

删除前先导出[数据库备份](/guide/database)。删除节点会清理其关联监控数据，无法直接撤销；这不会卸载机器上的 Agent，仍需在机器上运行[卸载命令](/guide/uninstall)。

## 管理 API 更新约定

`PATCH /api/admin/servers/{id}` 目前接收完整的节点配置 `ServerInput`，不是仅修改请求中出现的字段。自行编写管理脚本时，保留全部配置后提交；不要只发送单个字段，以免校验失败或把省略项恢复为默认值。后台页面已按完整配置提交。
