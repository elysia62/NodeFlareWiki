# 数据库与备份

NodeFlare 支持 SQLite 与 PostgreSQL 双数据库，两种数据库之间可**在线迁移**。相关操作均在后台「数据库」页面完成。

## 数据库管理

后台「数据库」页面支持查看占用、回收空间、导出 / 恢复 ZIP 备份，以及 SQLite ↔ PostgreSQL 在线迁移。

- 历史数据默认保留 30 天，按保留天数自动清理；
- 先缩短历史保留天数或清理历史数据，可以显著缩小备份体积。

## 备份与恢复

一键备份 / 恢复（ZIP）。备份内容包含：设置、节点、历史、通知、主题、任务与安全配置。出于安全考虑，备份操作需要 TOTP 或密码验证。

大小限制：

| 限制项 | 上限 |
| --- | --- |
| 备份 ZIP | 512 MiB |
| 解压后总大小 | 4 GiB |
| 条目数 | 16384 |
| 单个主题文件 | 32 MiB |

## 在线迁移

SQLite ↔ PostgreSQL 迁移注意事项：

- 迁移会**覆盖目标库**并自动更新连接串；
- 保留 Agent Token；
- 重启服务后生效；
- 使用 `--database` 命令行参数启动时，在线迁移功能会被禁用，见[配置](/guide/config#命令行参数)。
