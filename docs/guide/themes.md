# 主题定制

NodeFlare 内置主题商店，公开看板的主题可一键更换。

## 安装主题

主题商店提供三种安装方式：

- **内置主题**：开箱即用；
- **仓库主题一键安装**：直接从 GitHub 仓库安装；
- **本地 ZIP 上传**：上传主题 ZIP 包。

安装后可在后台自定义主题参数（站点名称、公告、Logo、背景图与显示项等）。

## 主题目录

主题解压目录由 `theme_dir` 配置，默认为配置目录下的 `themes`，见[配置](/guide/config#配置项)。

::: note
主题包含在[一键备份](/guide/database)中；单个主题文件大小限制为 32 MiB。
:::
