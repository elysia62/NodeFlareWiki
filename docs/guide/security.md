# 登录与安全

首次账号来自安装时填写的管理员用户名和密码。完成数据库初始化后，配置文件中的初始密码会自动清空；后续账号修改在后台「登录与安全」进行。

## 修改账号

新密码要求 8～128 个字符，输入两次确认；留空表示不修改密码。需要身份确认的操作会弹出验证框，按提示提供当前密码或 TOTP。不要把 Agent Token、通知凭证或数据库备份作为排错截图公开发送。

## TOTP 两步验证

1. 在「登录与安全」生成密钥，使用验证器保存二维码或密钥。
2. 点击启用并填写验证器当前的 6 位动态码。
3. 之后管理员登录需要动态码；每次远程执行也必须提交有效动态码。

妥善保管验证器恢复资料，确保后端和手机的系统时间正确。页面的「登录设备」可以查看现有会话并踢下线其他设备；踢下线后对应会话立即失效。

## Turnstile

后台分别提供「保护管理员登录」与「保护公开仪表盘」开关。填写与站点域名匹配的 Site Key 和 Secret Key，保存后分别验证登录页和公开页的效果。已经保存的密钥留空不会删除原值。

浏览器通过验证不等于登录一定成功：后端还需完成服务端验证，以及账号密码和已启用的 TOTP 校验。排错时检查后端网络、站点域名、密钥配对及日志，不要只依赖浏览器上的绿色通过标志。

## 网络与本地授权

脚本安装默认监听 `127.0.0.1:2206`；公开访问使用 HTTPS [反向代理](/guide/proxy)，并限制可信代理范围。

远程执行除了后台 TOTP 验证，还受 Agent 本地 `--disable-remote` 参数约束；网页无法覆盖这个禁用参数。开启与关闭的具体步骤见[节点远程执行](/guide/nodes#远程执行)。
